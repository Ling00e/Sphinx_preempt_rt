Installation
===========================

Dépendances:
----------------

Mettre à jour le système:
    .. code-block:: console

        $ sudo apt-get update
        $ sudo apt-get upgrade

Installer les outils:
    .. code-block:: console

        $ sudo apt-get install bc bison build-essential flex gcc libelf-dev libncurses-dev libssl-dev make
